# 🤝 Contributing to Cat Photo App Repository

Thank you for your interest in contributing! This guide will walk you through the entire process.

## 📋 Prerequisites

Before you start, make sure you have:
- A GitHub account
- Basic understanding of HTML
- Git installed on your computer (optional, but recommended)

## 🔄 Contribution Process

### Step 1: Fork the Repository

1. Click the **Fork** button at the top right of this repository
2. This creates a copy of the repository in your GitHub account

### Step 2: Build Your Cat Photo App

Follow the detailed tutorial in [docs/TUTORIAL.md](./docs/TUTORIAL.md) to build your Cat Photo App step-by-step.

### Step 3: Host with GitHub Pages

Once your app is complete, follow [docs/GITHUB_PAGES.md](./docs/GITHUB_PAGES.md) to host it using GitHub Pages.

### Step 4: Prepare Your Submission

1. In your forked repository, create a new folder under `submissions/` with your GitHub username:
   ```
   submissions/your-github-username/
   ```

2. Add your files to this folder:
   ```
   submissions/your-github-username/
   ├── index.html          # Your Cat Photo App
   ├── README.md           # Info about your submission
   └── screenshot.png      # Screenshot of your app (optional)
   ```

3. Create a `README.md` in your submission folder with:
   ```markdown
   # Cat Photo App by [Your Name]
   
   ## 🔗 Live Demo
   [View my Cat Photo App](your-github-pages-url)
   
   ## 📝 About
   Brief description of your experience building this app.
   
   ## 🎨 Customizations
   List any customizations you made (if any).
   
   ## 📅 Completed
   Date: YYYY-MM-DD
   ```

### Step 5: Create a Pull Request

1. Go to the original repository (sethunath2003/html-cat-photo-app)
2. Click **Pull Requests** → **New Pull Request**
3. Click **compare across forks**
4. Select your fork and branch
5. Click **Create Pull Request**
6. Fill in the PR template with your information

## ✅ Submission Checklist

Before submitting your PR, ensure:

- [ ] Your Cat Photo App is in a folder named `submissions/your-github-username/`
- [ ] Your folder contains `index.html` with your complete Cat Photo App
- [ ] Your folder contains a `README.md` with the required information
- [ ] Your Cat Photo App is hosted on GitHub Pages and the link works
- [ ] You've filled out the PR template completely
- [ ] Your HTML follows the freeCodeCamp tutorial structure
- [ ] All links in your app work correctly
- [ ] Your submission folder name matches your GitHub username

## 🤖 What Happens Next?

1. **Automated Bot Check**: Our GitHub bot will automatically:
   - Welcome you to the project
   - Verify your submission structure
   - Check for required files
   - Provide feedback if anything is missing

2. **Moderator Review**: Repository moderators will:
   - Review your code
   - Test your GitHub Pages link
   - Check for appropriate content
   - Approve and merge your contribution

3. **Feedback**: You may receive comments requesting changes. Don't worry! This is normal and part of the learning process.

## 📝 Submission Guidelines

### Do's ✅
- Follow the tutorial structure from freeCodeCamp
- Keep your code clean and readable
- Use proper HTML formatting
- Test your GitHub Pages link before submitting
- Be respectful and professional

### Don'ts ❌
- Don't submit incomplete work
- Don't include inappropriate content
- Don't copy someone else's submission
- Don't modify files outside your submission folder
- Don't submit without testing your GitHub Pages link

## 💡 Tips for Success

1. **Test Locally First**: Open your `index.html` in a browser before submitting
2. **Double-Check Links**: Make sure all images and links work
3. **Follow the Format**: Use the exact folder structure specified
4. **Be Patient**: Reviews may take a few days
5. **Learn from Others**: Check existing submissions for inspiration

## 🐛 Common Issues

### "My GitHub Pages link doesn't work"
- Make sure GitHub Pages is enabled in your repository settings
- Wait 5-10 minutes after enabling for the site to be live
- Check that your file is named exactly `index.html`

### "My PR was marked as invalid"
- Review the bot's comments
- Check the submission checklist above
- Make sure your folder structure is correct

### "I made a mistake in my submission"
- You can update your fork and the PR will automatically update
- Comment on your PR explaining the changes

## 🆘 Getting Help

If you're stuck:
1. Check the [docs/TUTORIAL.md](./docs/TUTORIAL.md) for detailed instructions
2. Review existing submissions for examples
3. Open an issue with the "question" label
4. Read the bot's automated feedback carefully
